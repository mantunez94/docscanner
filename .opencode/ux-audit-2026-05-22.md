## Recommendations (Top 5)

1. **Semantic labels across all screens** — Add `semanticLabel` to all `Image.file`, `IconButton`, custom painters, and onboarding indicators. This single fix addresses the most critical accessibility gap.

2. **Camera permission flow** — Implement `permission_handler` with a rationale dialog, `openAppSettings()` fallback, and a graceful recovery screen instead of "No camera found."

3. **Fix onboarding copy** — Remove or implement the "Filters & Adjustments" feature. The current text creates a false expectation.

4. **User-friendly error messages** — Replace all `SnackBar(content: Text('Error: $e'))` with mapped, human-readable messages. Log the raw exception with `debugPrint`.

5. **Fix SnackBar false positive** — Only show "Document saved" / "Pages added" when a scan was actually completed, not when the scanner is dismissed.
